 Rose Éclat — The Art of Fragrance

A luxurious and elegant perfume brand website designed with a soft pastel pink and white color palette. Rose Éclat showcases the beauty of fragrances through a modern design, smooth animations, and an elegant user experience.

 Features

- **Elegant Home Page** — A premium hero section with beautiful typography and animations.
- **Our Story** — Discover the inspiration and identity behind Rose Éclat.
- **Perfume Collection** — Explore a curated collection of men's and women's fragrances.
- **Contact Page** — Get in touch to learn more about fragrances.
- **GSAP Animations** — Smooth animations using GSAP and ScrollTrigger.
- **Responsive Design** — Optimized for desktop, tablet, and mobile devices.
- **Theme Toggle** — Switch between light and dark modes.
- **Font Awesome Icons** — Elegant icons for a polished interface.
